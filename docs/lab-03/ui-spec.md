# Sprint 3 UI Specification — Zen Green Theme — TokTickIT

## Theme Guidelines (Zen Green)
- **Primary Color:** Forest Green (`#1b4332`)
- **Accent Color:** Mint Green (`#52b788`)
- **Background:** Soft Gray / Off-white (`#f8f9fa`)
- **Card Background:** Pure White (`#ffffff`) with subtle border (`#e9ecef`)
- **Text:** Dark Gray (`#212529`)

## Screens
1. **Login Screen:** Clean centered card, input fields for email/password, submit button in Primary Green.
2. **Mandatory Password Change:** Banner alert informing user of mandatory password reset; form with new password & confirmation.
3. **IT Staff Ticket Queue:** Responsive table view, status pills (New=Blue, In Progress=Orange, Resolved=Green, Closed=Gray), IT Priority badges, search/filter controls.
4. **IT Staff Ticket Detail:** Two-column or tabbed view; left panel for ticket details/actions, right panel with dual tabs for "Public Comments" and "Internal Notes" (distinguished with yellow highlight for internal notes).
5. **Admin User Management:** Data table showing Name, Email, Role badge, Status toggle; modal for user creation and password reset.
